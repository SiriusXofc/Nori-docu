A Nori é uma plataforma de atendimento e automação para comunidades Discord. Esta documentação descreve somente as rotas públicas da API em `https://api.nori.qzz.io`.

<Note>
  Rotas de dashboard, tickets, painéis, configurações, auditoria, métricas e storage não fazem parte desta documentação pública. Elas exigem sessão ou credenciais específicas.
</Note>

## URL base

```text
https://api.nori.qzz.io
```

As respostas são JSON, salvo quando indicado o contrário. Use `Accept: application/json` nas integrações que esperam JSON.
