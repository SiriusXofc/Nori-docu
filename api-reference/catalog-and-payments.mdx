## `GET /public/capabilities`

Retorna as convenções públicas da API.

```bash
curl https://api.nori.qzz.io/public/capabilities
```

Campos principais:

```json
{
  "service": "Nori API",
  "apiVersion": "2026.08",
  "baseUrl": "https://api.nori.qzz.io",
  "documentation": "https://docs.nori.qzz.io",
  "authentication": {
    "type": "apiKey",
    "header": "X-Api-Key",
    "serverHeader": "X-Guild-Id"
  },
  "publicRoutes": []
}
```

O array `publicRoutes` contém as rotas sem API key. O objeto `protectedModules` identifica grupos que continuam protegidos.

## `GET /public/catalog`

Retorna o catálogo público de planos e módulos.

```bash
curl https://api.nori.qzz.io/public/catalog
```

```json
{
  "service": "Nori API",
  "plans": [],
  "modules": [],
  "links": {
    "documentation": "https://docs.nori.qzz.io",
    "support": "https://discord.gg/5GFRecexb7"
  }
}
```

`plans` e `modules` são arrays e podem mudar conforme os produtos publicados.

## `GET /payments/plans`

Retorna os planos disponíveis para o checkout público.

```bash
curl https://api.nori.qzz.io/payments/plans
```

Use a resposta como fonte de verdade para preço e disponibilidade. Não fixe valores comerciais no cliente.
