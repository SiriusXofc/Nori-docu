---
title: "Quickstart"
description: "Faça sua primeira chamada pública à Nori API."
---

## 1. Verifique a API

As rotas públicas de operação não exigem chave:

```bash
curl https://api.nori.qzz.io/health
```

Resposta esperada:

```json
{
  "ok": true,
  "status": "ok",
  "service": "nori-api"
}
```

## 2. Leia as capabilities

```bash
curl https://api.nori.qzz.io/public/capabilities
```

Essa resposta informa a versão pública anunciada, a URL base, o formato de autenticação das rotas protegidas e a lista de recursos públicos.

## 3. Consulte o catálogo

```bash
curl https://api.nori.qzz.io/public/catalog
```

O catálogo retorna planos, módulos e links públicos da Nori.

## 4. Trate erros

Considere qualquer status fora de `2xx` como falha. Respostas de erro usam o formato:

```json
{
  "error": "mensagem legível"
}
```

Leia também [Erros e limites](/errors-rate-limits) antes de colocar a integração em produção.

<Tip>
  Não coloque segredos em query strings. Para integrações autenticadas, use a documentação privada fornecida pela equipe da Nori.
</Tip>
